一覧・詳細・編集の組み合わせの例: 左の一覧で選び、右でその場の編集（ExpansionEditor）、まとめて削除は確認（Dialog）と「元に戻す」（Toast）。
*A screen pattern combining several components; also used for the scenario checks in README.*

**理由 / Why:** 一覧から選んだ人が知りたいのはその授業の中身なので、右側は名前と要点（時限・教室）を大きく上に出し、直せる項目は 1 つのまとまりに並べる。直せない項目も同じ並びに置き、直せない理由をすぐ下に書く。
*People who pick a course want its contents, so the right side leads with its name and key facts, and editable items sit in one group; read-only items share the row layout with the reason beneath.*
