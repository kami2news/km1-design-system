一覧と「予定を追加」ボタン、ドロワーの中のフォーム（エラーの一覧つき）、追加のお知らせ（Toast）を組み合わせた画面の例。
*A screen pattern combining several components; also used for the scenario checks in README.*

**理由 / Why:** 予定を足した人が知りたいのは「どの日のどの時刻に入ったか」なので、主役は日ごとに時刻順に並んだ予定にし、足した行は並んだ位置と「追加しました」の言葉で示す。入力はドロワーで、元の一覧を見たまま行う。
*People who add an event want to see where it landed, so the focal point is the day-by-day, time-ordered list; the new row shows its place and the words "追加しました". Input happens in a drawer, with the list still in view.*
