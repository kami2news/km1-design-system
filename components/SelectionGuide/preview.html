何をしたい？ / What is the user trying to do?
  • 移動する / Move
    • 別の主要な画面へ→Nav
    • 同じ画面の中で表示を切り替える→Tabs
    • 階層の中の現在地を示す・上に戻る→Breadcrumb
  • 値を選ぶ / Pick a value
    • 1 つ・5 件以下→RadioGroup
    • 1 つ・6〜15 件→Select
    • 1 つ・多い／名前で探す→Combobox
    • 複数・少ない→Checkbox
    • 複数・探して足す→TagPicker
    • すぐ反映するオン・オフ→Switch
    • 送信で確定するはい・いいえ→Checkbox
    • おおよその量→Slider
    • 正確な数→SpinButton
  • 同じ種類の集まりを見る / Browse a collection
    • 列で比べる・並べ替える→Table
    • 縦にざっと見て 1 つ選ぶ→List（＋ListSection）
    • 画像で見分ける→ImageGrid
    • 種類も長さもまちまち→Card
  • 対象に操作する / Act on items
    • いつも使う操作→Toolbar
    • 選んだものだけに効く操作→ContextualActionBar
    • たまに使う操作→Menu
  • 入力・編集する / Enter or edit
    • 一覧の 1 項目をその場で直す→ExpansionEditor
    • 順序のある 3 工程以上→StepFlow
    • 1 画面で済むまとまり→FormGroup ＋ Input など
    • 説明を開いて読むだけ→Accordion
  • 知らせる / Tell the user
    • 操作の結果を一時的に（元に戻す付き）→Toast
    • 画面に残す注意・警告→Alert
    • 判断が要る・取り消せない操作の確認→Dialog
    • 処理を待つ（10 秒以上は工程と時間）→Progress
  • 補助の情報・選択肢を重ねる / Overlay extra content
    • スマホで、今の画面を保ったまま→BottomSheet
    • PC で、押した場所の近くに→Popover／Menu
    • 詳しい作業・設定→Drawer／Dialog

上から順に当てはまるものを選ぶ。迷ったら「目的が 1 つに定まる部品」を選ぶ（M1 の「用途・目的が明確な UI」）。件数の目安（5・15 件）はデジタル庁デザインシステムと KM1 の既存の規則。/ Pick the first match. Thresholds come from the Digital Agency DS and existing KM1 rules.
