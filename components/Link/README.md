文中・文末のテキストリンク。常に下線を付け、色だけでリンクと分からせない。
*An inline text link. Always underlined so it is never identified by color alone.*

利用側が渡すもの: `href`、`children`（行き先が分かるラベル）。別タブで開く場合は `external`（読み上げ用の注記が自動で付く）。
*Consumer provides: `href`, `children` (a label that says where it goes). Use `external` for new tabs; a screen-reader note is added automatically.*

- やること: 「料金の詳細を見る」のように行き先が分かるラベルにする。
  *Do: use destination-describing labels such as "View pricing details".*
- やらないこと: 「こちら」「click here」だけのリンク、下線の削除。
  *Don't: use bare "here" links or remove the underline.*

**理由 / Why:** 別の場所へ移る。常に下線。色だけでリンクと分からせない。
*Go elsewhere: always underlined, never colour alone.*
